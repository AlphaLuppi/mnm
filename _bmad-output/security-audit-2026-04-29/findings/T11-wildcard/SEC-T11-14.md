## Description

`getChallengeStatus()` compares the challenge token and code using JavaScript `!==` (non-constant-time):

```typescript
function getChallengeStatus(token: string, code: string | undefined): ChallengeStatus {
  if (!activeChallenge) return "invalid";
  if (activeChallenge.token !== token) return "invalid";     // non-constant time
  if (activeChallenge.code !== (code ?? "")) return "invalid"; // non-constant time
  ...
}
```

JavaScript string comparison with `!==` short-circuits at the first differing character. For the token (48-character hex = 192-bit entropy) and code (24-character hex = 96-bit entropy), this creates a timing oracle: an attacker who can measure response time precisely enough can determine the length of the common prefix and recover the token/code character by character.

**Practical risk**: The entropy (192 bits for the token) is so high that a brute-force timing attack is computationally infeasible in practice. A successful attack would require millions of precisely-timed requests over days. This is classified as `info` because the entropy renders the attack non-practical.

However, it is worth noting because:
1. The `code` (24-char hex = 96 bits) has lower entropy and is also in the URL (visible in logs, browser history, the startup banner).
2. If the comparison were to be shortened in the future (e.g., to a 6-digit numeric code), the timing oracle would become very practical.

## Impact

- Theoretical: character-by-character timing oracle for token recovery.
- Practical risk: negligible due to 192-bit token entropy.

## Recommendation

Use `crypto.timingSafeEqual()` for consistency with the rest of the codebase:

```typescript
function getChallengeStatus(token: string, code: string | undefined) {
  if (!activeChallenge) return "invalid";
  const expectedToken = Buffer.from(activeChallenge.token);
  const givenToken = Buffer.from(token);
  if (expectedToken.length !== givenToken.length ||
      !crypto.timingSafeEqual(expectedToken, givenToken)) return "invalid";
  // similar for code
}
```
