## Description

The `resolveCompanyId` function in `tenantContextMiddleware` has a fallback chain:

```typescript
function resolveCompanyId(req: Request): string | undefined {
  // Priority 1: explicit route parameter
  const paramCompanyId = req.params.companyId as string | undefined;
  if (paramCompanyId) return paramCompanyId;
  // Priority 2: agent actor
  if (req.actor?.type === "agent" && req.actor?.companyId) return req.actor.companyId;
  // Priority 3: board user — first companyId
  if (req.actor?.type === "board" && req.actor?.companyIds?.length) return req.actor.companyIds[0];
  return undefined;
}
```

Priority 3 is dangerous: for a board user who belongs to multiple companies, if a route does NOT have `/companies/:companyId` in the path, the RLS context is set to `companyIds[0]` — the **first** company in the membership list (arbitrary ordering from the DB query in `actorMiddleware`).

Routes that go through `tenantContextMiddleware` without a path `companyId` include any API route NOT under `/companies/:companyId`. Looking at the app.ts mounting:

```typescript
api.use("/companies/:companyId", tenantContextMiddleware(db));
```

The middleware is ONLY mounted for `/companies/:companyId` paths. So this fallback only applies when tenantContextMiddleware is called manually from background code or if the mounting changes.

However: the middleware is exported as `tenantContextMiddleware` and could be used elsewhere. The fallback behavior is unsafe for multi-company users and should not exist.

## Impact

**MEDIUM.** If this middleware is ever mounted on a non-company-prefixed route, multi-company board users would have their RLS context set to their "first" company arbitrarily. This is silently incorrect behavior that could cause data cross-exposure or data hiding.

## Recommendation

Remove the Priority 3 fallback. If no `req.params.companyId` is present and the actor is a board user, either:
- Return `undefined` (RLS will clear the context)
- Throw an error

```typescript
function resolveCompanyId(req: Request): string | undefined {
  const paramCompanyId = req.params.companyId as string | undefined;
  if (paramCompanyId) return paramCompanyId;
  if (req.actor?.type === "agent" && req.actor?.companyId) return req.actor.companyId;
  // NO board fallback — board users must always use explicit company path
  return undefined;
}
```
