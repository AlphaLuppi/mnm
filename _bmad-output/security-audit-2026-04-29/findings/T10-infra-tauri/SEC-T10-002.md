## Description

`analyzeDriftViaCLI()` constructs a shell command string and passes it to `execFileAsync("bash", ["-c", ...])`:

```typescript
const tmpFile = path.join(os.tmpdir(), `mnm-drift-${crypto.randomUUID()}.txt`);
await fs.writeFile(tmpFile, prompt, "utf-8");

const { stdout } = await execFileAsync(
  "bash",
  ["-c", `cat "${tmpFile}" | claude --dangerously-skip-permissions -p - --output-format text`],
  { maxBuffer: 10 * 1024 * 1024, timeout: 120_000 },
);
```

The `tmpFile` path is generated using `crypto.randomUUID()`, which is safe. However, the entire command is passed to `bash -c` as a string, which means:

1. Any future change that makes `tmpFile` user-influenced would be immediately exploitable.
2. More critically: the invocation uses `bash -c "..."` (shell interpretation) instead of `execFile` with a safe argument array. This is an anti-pattern that violates the principle of avoiding shell interpretation.
3. The command also invokes `claude --dangerously-skip-permissions` which completely disables Claude Code's permission sandbox, granting arbitrary filesystem and network access to the Claude CLI running inside the container.

Additionally, `os.tmpdir()` on Linux is `/tmp` which is world-writable. A symlink attack in `/tmp` (TOCTOU) could redirect the write to an arbitrary file.

## Impact

- The `--dangerously-skip-permissions` flag means if this path is triggered, Claude Code runs with no restrictions inside the container.
- If the CLI fallback is triggered by user-controlled workflow content, and if any future change to the prompt path makes `tmpFile` influenced by user data, shell injection becomes trivially exploitable.
- TOCTOU on `/tmp` symlink could allow overwriting server-accessible files.

## Reproduction

1. Trigger drift analysis with no `ANTHROPIC_API_KEY` set (activates CLI fallback).
2. The call path: route → `analyzeDrift()` → `analyzeDriftViaCLI()` → `bash -c "cat ..."`.
3. If the UUID generation were ever replaced with a user-influenced value, inject: `"; rm -rf /; "` in the path.

## Recommendation

1. Use `execFile` with explicit argument arrays instead of `bash -c`:
   ```typescript
   const { stdout } = await execFileAsync(
     "claude",
     ["--dangerously-skip-permissions", "-p", "-", "--output-format", "text"],
     { input: prompt, maxBuffer: ..., timeout: ... }
   );
   ```
   This eliminates shell interpretation entirely and removes the need for a temp file.
2. Remove `--dangerously-skip-permissions` — use scoped Claude Code with proper permissions.
3. If a temp file is still needed, use `fs.mkstemp()` or create in a subdirectory owned exclusively by the process.
