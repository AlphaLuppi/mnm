## Description

The `.gitignore` correctly lists `e2e/.auth/` as excluded, but the following files are present in the working tree:

```
e2e/.auth/adminStorageState.json
e2e/.auth/atelierAdminStorageState.json
e2e/.auth/contributorStorageState.json
e2e/.auth/managerStorageState.json
e2e/.auth/storageState.json
e2e/.auth/viewerStorageState.json
```

Current file content: all contain `{"cookies":[],"origins":[]}` (empty — no active tokens). This indicates they were generated by the test runner after setup but contain no sensitive session data at this time.

However:
1. If these files were ever committed to git history (before the `.gitignore` rule was in place), they may contain real session cookies in the git history.
2. After a real test run against an authenticated deployment, these files would contain valid session cookies for admin, manager, contributor, viewer, and atelierAdmin roles. If they are accidentally committed, those sessions become compromised.
3. The `playwright.config.ts` references `storageState: "e2e/.auth/storageState.json"` which is loaded directly — if this file is stale from a previous run against production, it provides authenticated access.

## Impact

- Low risk currently (files are empty).
- Risk escalates if: (a) they're committed to git with real tokens, (b) a CI system commits them as artifacts.
- The admin storage state would give full admin access to any server it was generated against.

## Reproduction

1. `git log --all --full-history -- "e2e/.auth/*"` — check if these files were ever in git history.
2. Run tests against a real server: `e2e/.auth/adminStorageState.json` will contain active session cookies.

## Recommendation

1. Verify the files are not in git history: `git ls-files e2e/.auth/` should return empty.
2. If they appear in history: run `git filter-repo` or BFG Repo Cleaner to remove them.
3. Add an explicit pre-commit hook that rejects any file matching `e2e/.auth/*.json` if it contains non-empty cookies.
4. In CI, explicitly delete `e2e/.auth/` before and after test runs.
