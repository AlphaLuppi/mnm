## Description

Agent JWTs include a `jti` (JWT ID) claim as a UUID (`randomUUID()` at creation), but the verifier never checks this value against any revocation list or "already-used" store:

```typescript
// verifyLocalAgentJwt — no jti lookup anywhere in the function
// The jti is simply decoded and returned, never validated for uniqueness
jti: typeof claims.jti === "string" ? claims.jti : undefined,
```

A stolen agent JWT is thus fully replayable within its `exp` window (default 2 hours, configurable via `MNM_AGENT_JWT_TTL_SECONDS`). The attacker does not need the signing secret — they only need to intercept the token.

**Token exposure vectors:**
- Tokens are passed in the `Authorization: Bearer` header. TLS termination at a proxy, or a misconfigured `http://` deployment, could expose them.
- Tokens may appear in HTTP access logs (many proxies log request headers).
- MCP tool parameters might log the calling JWT.

The MCP token verifier (`mcp-token-verifier.ts`) has the same issue — it extracts `jti` from MCP OAuth tokens but does not validate it against any revocation store.

## Impact

- A stolen agent JWT can be replayed for up to 2 hours to impersonate the agent and perform any action the agent is authorized for (including creator permission inheritance per SEC-T1-006).
- No server-side mechanism exists to detect or stop the replay.

## Reproduction

1. Intercept or extract an agent JWT from HTTP headers or logs.
2. Replay it within the `exp` window to any agent-accessible endpoint.
3. Observe the request succeeds as the agent.

## Recommendation

- For high-value flows (e.g., admin actions, credential access), implement short-lived JWTs and validate `jti` against a Redis or DB-backed "used tokens" set (TTL = token TTL).
- Alternatively, switch to API keys for long-lived agents and reserve JWTs for ephemeral run tokens. API keys already have a revocation mechanism (`revokedAt` column).
- At minimum, reduce the default JWT TTL from 2 hours to a shorter window (15–30 minutes) to reduce the replay window.
- Log a warning when a JWT is used near its expiry (potential replay attempt).
