## Description

The following security controls were verified to be correctly implemented:

**Timing-safe comparisons** — All token comparison operations use `timingSafeEqual` from `node:crypto`:
- Agent JWT signature: `agent-auth-jwt.ts:71–76` (`safeCompare`)
- MCP token verifier: `mcp-token-verifier.ts:34`
- OAuth client_secret: `mcp-oauth-router.ts:673, 828`
- PKCE verification: `mcp-oauth-router.ts:48`
- API key hash comparison: `middleware/auth.ts:83` (hash-then-compare, no timing leak)

**PKCE S256 enforcement** — The MCP OAuth flow enforces S256 only:
- Authorization endpoint rejects any `code_challenge_method` that is not `S256` (`mcp-oauth-router.ts:360`).
- The well-known metadata only advertises `S256` (`mcp-oauth-router.ts:224`).
- PKCE `code_verifier` is verified at the token endpoint before issuing tokens (`mcp-oauth-router.ts:706`).

**Authorization code single-use** — `OAuthStore.consumeCode()` deletes the code before returning it (`oauth-store.ts:141–142`). Race conditions are mitigated because `this.codes.delete(code)` executes synchronously before any async work.

**Refresh token hashing** — Refresh tokens are stored as SHA-256 hashes in the DB (`oauth-store.ts:45, 163, 177`). The raw token is only transmitted once (on issuance) and never stored in plaintext.

**Anti-clickjacking on OAuth routes** — `X-Frame-Options: DENY` and `Content-Security-Policy: frame-ancestors 'none'` are set on all OAuth routes (`mcp-oauth-router.ts:182–185`).

**UUID validation on companyId** — Both `assertCompanyMembership` and `tenantContextMiddleware` validate UUID format before processing (`company-access.ts:27`, `tenant-context.ts:57`), preventing path traversal and injection via the `:companyId` parameter.

**RLS tenant context cleanup** — `tenantContextMiddleware` registers `res.on("close")` and `res.on("finish")` listeners to clear the PostgreSQL session variable after every request, preventing tenant context leak across pooled connections.

## Impact

None — these are correctly implemented controls. No remediation needed.
