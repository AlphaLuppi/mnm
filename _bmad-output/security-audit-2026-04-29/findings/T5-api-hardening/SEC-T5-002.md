## Description

The Jira import feature (`POST /api/companies/:companyId/import/jira/connect`, `/preview`, `/start`) accepts a user-controlled `baseUrl` field and immediately makes outbound HTTP requests to it via `jiraFetch()`. The Zod schema validates only that the value is a syntactically valid URL starting with `http://` or `https://`. There is **no filtering** against:

- Private RFC-1918 addresses (10.x.x.x, 172.16-31.x.x, 192.168.x.x)
- Loopback (127.0.0.1, ::1, localhost)
- Link-local (169.254.x.x — EC2 IMDS)
- Cloud metadata endpoints (http://169.254.169.254/latest/meta-data/, http://[fd00:ec2::254]/)

An attacker with `PROJECTS_MANAGE` permission can probe or read responses from internal services by submitting crafted `baseUrl` values.

```typescript
// jira-client.ts:31-48
async function jiraFetch<T>(path: string, ...): Promise<T> {
  const url = `${normalizedBase}/rest/api/3/${path}`;
  const res = await fetch(url, { ... });   // No IP block
  ...
  return res.json();  // Response body returned to caller
}
```

Additionally, the `GET /api/invites/:token/test-resolution` endpoint (`access.ts:1803`) makes a HEAD request to any `https?://` URL but does at least use `redirect: "manual"` to suppress redirect following — however the IP restriction is missing there as well.

## Impact

- Cloud deployments: exfiltration of EC2/GCP instance metadata (API keys, IAM credentials, internal IPs).
- Private deployments: port scanning and service probing of the internal network.
- The JSON response from internal services (HTTP 200) is forwarded verbatim to the attacker.

## Reproduction

```
POST /api/companies/COMPANY_ID/import/jira/connect
{
  "baseUrl": "http://169.254.169.254",
  "email": "attacker@example.com",
  "apiToken": "x"
}
```
Response body will contain whatever the IMDS returns for `/rest/api/3/serverInfo`.

## Recommendation

Add an SSRF guard before making any outbound request:
```typescript
import { isPrivateIP } from 'private-ip'; // or implement from scratch

function assertPublicUrl(raw: string) {
  const parsed = new URL(raw);
  const ip = await dns.lookup(parsed.hostname);
  if (isPrivateIP(ip.address)) throw new Error('Private/reserved IP blocked');
}
```

Block at minimum: loopback, link-local (169.254.0.0/16), RFC-1918, IPv6 equivalents. Apply the guard in `createJiraClient`, `probeInviteResolutionTarget`, and any future URL-fetch helper.
