## Description

Multiple list endpoints accept `?limit=` and `?offset=` query parameters but pass them to the database **without an upper-bound check**:

```typescript
// artifacts.ts:55-56
const limit = req.query.limit ? Number(req.query.limit) : undefined;
const offset = req.query.offset ? Number(req.query.offset) : undefined;
```

`Number("Infinity")` returns `Infinity`. `Number("1e9")` returns 1,000,000,000. Both pass a `?limit=` truthy check and are forwarded to the service. SQL `LIMIT Infinity` or `LIMIT 1000000000` will attempt to return the entire table.

Affected routes (confirmed no upper-bound):
- `GET /companies/:companyId/artifacts` (artifacts.ts:55)
- `GET /companies/:companyId/artifacts/:id/versions` (artifacts.ts:200)
- `GET /companies/:companyId/channels` (chat.ts:72)
- `GET /companies/:companyId/channels/:id/messages` (chat.ts:137)
- `GET /companies/:companyId/channels/:id/messages` with `?limit=50` default but still no cap (chat.ts:286)
- `GET /companies/:companyId/chat-shares` (chat-sharing.ts:131)
- `GET /companies/:companyId/drift-reports` (drift.ts:76, 100, 241)
- `GET /companies/:companyId/folders` (folders.ts:76)
- `GET /companies/:companyId/documents` (documents.ts:134)

Notable contrast: `agents.ts:1530` properly clamps: `Math.max(1, Math.min(1000, parseInt(limitParam, 10) || 200))`. The `project-memberships.ts:29` and `governed-workflows-ui.ts:510` also clamp properly. The pattern is inconsistently applied.

Also: `Number(req.query.limit)` where `req.query.limit` is `"NaN"` or `"abc"` produces `NaN`, which — if passed to an ORM — may cause a DB error whose message could leak schema info.

## Impact

- Authenticated actors can trigger full-table scans by passing `?limit=1000000&offset=0`.
- `NaN` values may produce unexpected ORM behaviour or DB error messages.

## Reproduction

```bash
curl "http://localhost:3100/api/companies/COMPANY_ID/artifacts?limit=Infinity"
curl "http://localhost:3100/api/companies/COMPANY_ID/folders?limit=9999999"
```

## Recommendation

Create a shared pagination helper:
```typescript
function parsePagination(query: qs.ParsedQs, defaults = { limit: 50, maxLimit: 200 }) {
  const limit = Math.max(1, Math.min(defaults.maxLimit,
    Number.isFinite(Number(query.limit)) ? Number(query.limit) : defaults.limit));
  const offset = Math.max(0,
    Number.isFinite(Number(query.offset)) ? Number(query.offset) : 0);
  return { limit, offset };
}
```
Apply it consistently to all list endpoints.
