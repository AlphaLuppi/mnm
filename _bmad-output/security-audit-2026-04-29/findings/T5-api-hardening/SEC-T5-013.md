## Description

The deployment proxy middleware for `/preview/:deploymentId/*` checks:

```typescript
// deployment-proxy.ts:37-43
const hasSession = !!(req as any).actor;
const hasValidToken = shareTokenParam && shareTokenParam === info.shareToken;

if (!hasSession && !hasValidToken) {
  res.status(401).json({ error: "Authentication required..." });
  return;
}
```

The `req.actor` check is `!!actor` — truthy on **any** non-null actor, including `{ type: "none", source: "none" }` which is the default for unauthenticated requests in `local_trusted` mode.

In `authenticated` mode, `actorMiddleware` sets `req.actor = { type: "none", source: "none" }` initially. This is always truthy since it's an object, not null/undefined. Therefore `hasSession` is **always `true`** regardless of authentication status.

This means:
1. Any unauthenticated request to `/preview/:uuid/` passes the auth check in all deployment modes.
2. The share token path is redundant — it's never reached.
3. Deployment previews are accessible without credentials.

Note: the proxy proxies to `127.0.0.1:${port}` (internal only), so this is only exploitable for internal deployments, but the intent of the auth check is clearly broken.

## Impact

- Deployment preview endpoints are publicly accessible in `authenticated` mode.
- Bypasses the share token mechanism entirely.

## Reproduction

```bash
# No auth header — should 401 but will proxy through
curl http://localhost:3100/preview/DEPLOYMENT-UUID/
```

## Recommendation

Fix the auth check:
```typescript
const isAuthenticated =
  req.actor.type === "board" ||
  req.actor.type === "agent";
const hasValidToken = shareTokenParam && info.shareToken && shareTokenParam === info.shareToken;

if (!isAuthenticated && !hasValidToken) {
  res.status(401).json({ ... });
  return;
}
```

Also validate the share token with a constant-time comparison:
```typescript
import { timingSafeEqual } from "node:crypto";
const tokensMatch = shareTokenParam && info.shareToken &&
  timingSafeEqual(Buffer.from(shareTokenParam), Buffer.from(info.shareToken));
```
