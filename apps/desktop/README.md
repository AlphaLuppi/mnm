# MnM Desktop

**Tauri 2** native desktop shell for MnM — wraps the existing React web app in a lightweight, fast native macOS window (with Windows and Linux planned).

## What This Is

MnM Desktop is a native cockpit for AI agent supervision that runs on your machine. It's not a separate app — it's the same React-based web interface (`@mnm/ui`) embedded in a Tauri window with native OS features. Think of it as the web app, but fast, offline-capable, and with direct access to your file system and clipboard.

**Sprint 1 POC status:**
- ✅ Web app loads and renders in Tauri window
- ✅ Type-safe IPC via tauri-specta
- ✅ DMG builds (unsigned, triggers Gatekeeper on first run)
- ⏳ No code signing, notarization, or auto-updater yet (Sprint 2)
- ⏳ Backend connection requires Vite dev proxy (production DMG can't reach API)

## Prerequisites

- **macOS 11+** (arm64 Apple Silicon or x64 Intel)
- **Rust 1.85+**: `rustup update stable`
- **Xcode Command Line Tools**: `xcode-select --install`
- **Bun 1.3+** (workspace package manager)
- **cargo-tauri CLI**: `cargo install tauri-cli --version "^2.0" --locked`

All bootstrap scripts run this automatically. Verify with:

```bash
rustc --version        # 1.85.0+
bun --version          # 1.3+
cargo tauri --version  # 2.0+
```

## Quick Start

```bash
# From monorepo root, install all workspace dependencies
bun install

# Dev mode: launches Vite dev server + Tauri window in parallel
# (UI hot-reloads as you edit React code)
bun run dev:desktop

# Production build: creates unsigned DMG
# Output: apps/desktop/src-tauri/target/release/bundle/dmg/MnM_0.1.0_aarch64.dmg
bun run build:desktop

# Or run Tauri dev directly from apps/desktop/
cd apps/desktop
bun run dev
```

## Architecture

```
apps/desktop/
├── package.json                    # npm scripts, tauri-cli dep
├── src-tauri/                      # Rust shell
│   ├── Cargo.toml                  # Rust deps (tauri, serde, tauri-specta)
│   ├── tauri.conf.json             # Window, security, bundle config
│   └── src/
│       ├── main.rs                 # Entry point
│       ├── lib.rs                  # Init & command registration
│       └── commands.rs             # IPC handlers (ping, appInfo, etc.)
├── src/
│   ├── bindings.ts                 # Auto-generated by tauri-specta
│   └── main.tsx                    # Tauri entrypoint (loads @mnm/ui)
└── public/
    └── index.html                  # Loader HTML (loaded from file:// in prod)

@mnm/ui                             # Shared React app (located at packages/ui/)
```

### Key Design Choices

**UI Loading:**
- Dev: loads from `http://localhost:5173` (Vite dev server)
- Prod: loads from `../../../ui/dist/` relative path (prebuilt static files)

**IPC Bindings:**
- Rust commands exposed via `tauri-specta` with derive macros
- TypeScript types auto-generated at compile time to `src/bindings.ts`
- Never manually edit bindings — they regenerate on every Rust debug build

**Window Spec:**
- Default: 1440×900 (common laptop width)
- Min: 1024×640 (mobile-landscape minimum)
- Background: `#1c1917` (dark stone) to avoid white flash during load

## IPC Commands (Sprint 1)

```typescript
// Generated in src/bindings.ts — import and use in React:
import { ping, appInfo } from './bindings'

// Smoke test
const greeting = await ping('World')
console.log(greeting)  // "Hello, World!"

// Get app metadata
const info = await appInfo()
console.log(info)  // { version: "0.1.0", os: "macos", ... }
```

Full reference in `apps/desktop/src-tauri/src/commands.rs`.

## Known Limitations (Sprint 1)

| Limitation | Workaround | Sprint |
|---|---|---|
| **No code signing** | Right-click app → Open to bypass Gatekeeper warning | 2 |
| **No notarization** | DMG may be blocked on some machines | 2 |
| **No auto-updater** | Manual download from landing page | 2 |
| **Relaxed CSP** | `null` — safe for POC, hardened in Sprint 2 | 2 |
| **Backend unreachable in prod** | Use dev workflow (Vite proxy) — packaged DMG is offline-only for now | 2 |
| **No native macOS polish** | Basic window, no Liquid Glass or traffic light styling | 3 |

## Security (Sprint 1 to Sprint 2)

**Current (POC):**
- CSP is intentionally `null` — relaxed for fast iteration
- Capabilities trimmed to essential: `core:default`, `core:window:default`, `core:event:default`
- No secrets stored locally

**Sprint 2 (Planned):**
- Strict CSP: `default-src 'self'; connect-src 'self' https://api.mnm.com`
- OAuth tokens → Keychain via `tauri-plugin-keyring`
- `cargo audit` + `bun audit` in CI
- Hardened Runtime macOS entitlements
- Code signing + Apple notarization

**Sprint 3+:**
- SBOM generation
- Certificate pinning
- SQLCipher for local logs
- 33 security measures from brainstorm (see `_bmad-output/brainstorming/brainstorming-mnm-desktop-native-2026-04-07.md`)

## Troubleshooting

### "edition2024 required"
```bash
rustup update stable
```

### "icon not found" when building
```bash
cd apps/desktop
cargo tauri icon ../../ui/public/android-chrome-512x512.png
```

### White flash on startup
Already fixed via `backgroundColor: #1c1917` in `tauri.conf.json`. If you see it, check that config hasn't been overwritten.

### "Backend connection refused" when running DMG
Expected in Sprint 1 — the packaged app has no proxy. Dev workflow (`bun run dev:desktop`) works fine. Sprint 2 will add backend connectivity to packaged builds.

### Gatekeeper warning on macOS
Right-click the DMG → Open. This is normal for unsigned apps. Sprint 2 adds code signing + notarization.
